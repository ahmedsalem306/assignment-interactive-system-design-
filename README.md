# Flutter Navigation Assignment

A three-page Flutter app with Home, About, and Contact screens. It includes a custom app theme, bottom navigation, Home -> About and About -> Contact actions, icons, and a bundled home illustration.

## Run on the web

Install Flutter, then run:

```sh
flutter pub get
flutter run -d chrome
```

## Navigation

- Home: **Discover About Us** opens About.
- About: **Get in Touch** opens Contact.
- The bottom navigation bar opens any page directly.
